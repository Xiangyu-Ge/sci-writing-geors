# 10 · 图件与制图

先图后文：先把全套图表做到可投稿水平再动笔。图就是大纲，每个结果小节对应一张图；写着写着"没东西可写"，通常意味着图还没做完。

## 1. 基本要求

- 图文数据一致：正文中的数字与图中的数字对得上
- 字号要大：缩到期刊版面宽度后仍清晰可读
- 色盲友好配色
- 图题说明每个子图分别是什么：*(a) …; (b) …; (c) …*
- 图中不便解释的符号、颜色、缩写，在图例或图题中解释；读者不看正文也能读懂这张图
- 每张图在正文中至少引用一次，按首次引用的顺序编号
- 分辨率以期刊要求为准（位图通常不低于 300 dpi）；表格用三线表，不用竖线

## 2. 配色

彩虹色（jet、rainbow）和红绿色带会在数据中制造虚假边界，色觉障碍读者也无法读取（Crameri et al., 2020, Nature Communications）。改用感知均匀的科学色带：batlow、viridis、cividis、cmocean、ColorBrewer。

| 数据类型 | 色带 | 例 |
|---|---|---|
| 连续、单向 | 顺序色带（亮度单调变化） | 盐分、SOC、NDVI |
| 有正负、有中点 | 发散色带，0 对齐中间色 | 趋势斜率、变化量、残差 |
| 类别 | 定性色带，类别数不超过 8 | 土地利用、盐渍化等级 |

## 3. 地图

- **研究区图**：位置图（国家或区域尺度的插图）+ 研究区 + 采样点 + 关键地物；指北针、比例尺、经纬网或坐标系
- **专题图**：图例写清单位和分级；分级方法（等间距、分位数、自然断点）在方法或图题中说明
- **不确定性**：与预测图并排，或在同一图中用透明度、分级表达。Geoderma 2025 年一项面向 263 名用户的研究表明，常规的"高分辨率 + 单独的不确定性栅格"表达方式并不总是最便于决策，可考虑空间聚合或整合表达

## 4. 常用图型

| 结果 | 图型 |
|---|---|
| 反演精度 | 实测–预测散点图 + 1:1 线 + 指标标注 |
| 模型比较 | 分组柱状图或泰勒图 |
| 变量重要性 / SHAP | 排序条形图、SHAP 蜂群图、依赖图 |
| 时空变化 | 趋势斜率图 + 显著性掩膜；时间序列折线 + 突变点 |
| 驱动归因 | 贡献率空间图、堆叠条形图（各部分加和为整体时） |
| 方法框架 | 技术路线图，放在方法开头 |

## 5. 常见问题

- 正文数字与图不一致
- 子图没有 (a)(b)(c) 标注，或图题没说明每个子图
- 缩写、颜色、符号在图中出现却没有解释
- 字号过小，缩放后看不清
- 用彩虹色或红绿色带
- 发散数据用了顺序色带，或 0 没有对齐中间色
