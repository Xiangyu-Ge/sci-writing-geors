# 15 · 投稿前检查清单

写完一遍后逐项打勾，打不上勾就回去改。不要一次看完整张清单：写完哪一部分，就查对应的那几节；全部改完后，用 L 节的五道题自测。

## A · 选刊与整体结构

- [ ] 目标期刊已定，读过 aims & scope 和 Guide for Authors
- [ ] 遥感期刊：能写出"遥感贡献句"（遥感问题 + 技术推进 + 验证条件 + 地学意义）
- [ ] 创新点到了第 2 层（新视角、新现象、机理解释），或第 1 层已与已有产品和文献比较
- [ ] 章节顺序和结构变体（如 Results and Discussion 合写）与目标期刊一致
- [ ] 各部分篇幅与 4 篇目标期刊近作相当
- [ ] 主贡献在摘要、引言末尾、讨论结尾都出现
- [ ] 引言的每个 gap 和目标，讨论里都有回应
- [ ] 没有与论点无关的段落和句子

## B · 标题、摘要与 Highlights

- [ ] 标题讲出主要发现或主要工作，含研究区和时间尺度
- [ ] 关键词前置，前 6 个词能识别主题；复合名词链 ≤ 3；无工作标题痕迹
- [ ] 标题、摘要、Highlights 中没有 novel、robust、comprehensive 等评价词
- [ ] 摘要：背景 1 句、空白 1 句、方法 2–3 句、结果 2–3 句、意义 1 句
- [ ] 摘要第一句具体，结果有关键数字，能独立读懂
- [ ] 摘要无文献、图表、公式；新缩写 ≤ 3 个
- [ ] Highlights 3–5 条，每条 ≤ 85 字符，带数字或可验证的事实

## C · 引言

- [ ] 第一段用权威报告或论文的数据说明为什么值得关注，篇幅短
- [ ] 没有"随着……的快速发展"式开头，没有只讲危害
- [ ] gap 按 A→B→C 推进，C 具体到能被本研究的数据回答
- [ ] 论证了为什么用遥感或定量手段
- [ ] 最后一段直接写三个目标，与 gap 一一对应
- [ ] 没有写成综述；没有透露全部结果

## D · 研究区、数据与方法

- [ ] 研究区四类必含要素齐全：经纬度范围、气候地形水文、土壤和植被类型、环境问题或研究意义
- [ ] 研究区按"位置→自然→人文→科学意义"组织，末句收敛到研究问题；有研究区图
- [ ] 实测数据写了采样设计、样点数、样品支撑、采样与过境的时间差、仪器与方法
- [ ] 遥感与辅助数据参数齐全，有数据汇总表
- [ ] 方法开头有技术路线图
- [ ] 常用方法：定义 → 原理 → 步骤与优势 → 参数 → 平台与版本
- [ ] 新方法：写清改了哪里、为什么改，配图
- [ ] 每个参数都说明了为什么这样设置
- [ ] 每个缩写首次出现时有全称
- [ ] 读者分得清哪些是你做的、哪些是引用的

## E · 验证、不确定性与可解释性

- [ ] 验证方案（划分方式、指标）在方法中交代，并说明理由
- [ ] 优先使用独立验证集，或建模集/验证集划分
- [ ] 特征筛选、标准化、调参只在建模集上做，没有数据泄漏
- [ ] 报告了验证集的 R²、RMSE、MAE（及 RPD、bias）
- [ ] 与简单基线、已有产品或前人结果比较过
- [ ] 分类图：概率抽样、面积加权误差矩阵、置信区间
- [ ] 至少给了一种不确定性表达
- [ ] SHAP 前处理了共线性；SHAP 结论有理论或文献支撑，没有写成因果

## F · 结果

- [ ] 结果顺序与方法一致，每个结果对应一个研究目标
- [ ] 每段按五步：总起 → 关键信息与比较 → 说明什么 → 其他发现 → 小结与承接
- [ ] 精度验证结果和模型比较在结果中；与前人文献的比较留到讨论
- [ ] 评价靠幅度和对比，没有堆砌 striking、remarkable、notably
- [ ] 负面或不完美的结果也已报告
- [ ] 时空变化类：趋势斜率 + 显著性 + 面积比例 + 空间格局；有归因时给出相对贡献

## G · 讨论

- [ ] 3–4 个小节：2–3 个主要观点 + 不确定性、局限与展望
- [ ] 与前人比较讲清了异同，并解释了原因
- [ ] 机理解释覆盖时间尺度、空间尺度，兼顾自然因素与人类活动
- [ ] 反演类有光谱机制或遥感物理解释
- [ ] 语气与证据强度匹配；没有把相关写成因果，也没有防御性地堆砌限定词
- [ ] 局限具体，说明了对结论边界的影响
- [ ] 不是结果的重复，也不是文献综述；结尾有明确的意义或管理含义

## H · 结论

- [ ] 一段，100–200 词，比摘要更凝练
- [ ] 写出了方法、解决的问题、主要发现、学科贡献与意义
- [ ] 无背景句、无新内容、无文献
- [ ] 最后一句有力，不是"需要进一步研究"

## I · 图表

- [ ] 图文数据一致
- [ ] 字号足够大；色盲友好；没有彩虹色或红绿色带
- [ ] 图题说明了每个子图；符号、颜色、缩写在图例中解释
- [ ] 每张图在正文中引用并按顺序编号；表格为三线表
- [ ] 地图有指北针、比例尺、坐标系；图例写明单位

## J · 语言

- [ ] 关键术语全文一致
- [ ] 时态切换有意义；被动句不丢主权
- [ ] 句间用关键词重复和代词衔接；信号词一段最多各一次
- [ ] 结构层面的 AI 痕迹已检查：拔高意义、段末空泛总结、三连排比、空主语开头、频繁破折号
- [ ] AI 高频词（delve、pivotal、underscore、crucial、notably 等）已替换或控制在一两处
- [ ] 没有中式英文残留（见 `12-grammar-style.md` §15）
- [ ] 30 词以上的长句已检查能否拆分

## K · 引用与投稿材料

- [ ] 正文引用与参考文献列表一一对应；不在一处堆叠 [1–15]
- [ ] 每个"前人发现了 X"的论断都有引用；AI 推荐的文献逐条核实过
- [ ] 近 3–5 年的文献占相当比例；DOI 齐全
- [ ] Cover letter 一页以内，期刊名正确，发现直接陈述
- [ ] 作者顺序、CRediT、基金、利益冲突、数据可得性、AI 使用声明齐全

## L · 投稿前自测五问

答不出任何一题，说明还没准备好：

1. take-home message 用一句话（30 词以内）怎么说？
2. 最大的贡献是方法、结果、理论、应用中的哪一个？
3. 审稿人会问的第一个问题是什么？
4. 本文最弱的地方是什么？
5. 三年后这篇论文还会被读、被引用吗？为什么？
