# 00 · 选刊与期刊定位

动笔前先定目标期刊。期刊决定了论文要讲哪种贡献、篇幅多长、讨论多深，也决定了编辑初筛时问的第一个问题。

## 1. 目标期刊池（新锐期刊分区表 2026 · 1 区，地理学相关）

## 2. 编辑初筛的第一个问题

### 遥感类期刊（A 组）：遥感是科学对象，还是只是输入数据？

这是遥感期刊桌面拒稿最常见的原因。各刊的侧重点：

| 期刊 | 编辑看重 | 常见退稿信号 |
|---|---|---|
| RSE | 遥感科学的推进，有定量或生物物理意义，能跨尺度做环境推断 | 读起来像局地的常规应用 |
| ISPRS J P&RS | 摄影测量、遥感、地理空间方法本身 | 像通用计算机视觉换了一套遥感数据；下游应用比遥感更像主角 |
| IEEE TGRS | 方法在传感器、场景、地域、时相变化下是否站得住 | 遥感只是数据集 |
| Remote Sensing (MDPI) | 明确的遥感结果，投对分区 | 领域论文只是用了卫星数据；把数据集描述当成遥感进展 |

**遥感贡献句（四要素）**：遥感问题 + 技术推进 + 验证条件 + 地学或测量意义。投稿前写出这一句；写不出来，说明这篇更适合投领域期刊（C、D、H 组）。

### 领域期刊（C、D、H 组）：地学问题是否成立？

编辑关心的是地理、生态、土壤问题本身，遥感和模型只是手段。论文的主线要落在过程、机制、格局或管理含义上，方法写清楚即可，不必反复强调算法新颖。

### 冲刺档（F 组）：会不会改变人们看待某个基本问题的方式？

- 意义必须让非本领域的读者也看得懂
- 只把一个子领域推进一大步的工作，属于专业期刊
- 编辑先看摘要和主图，再决定是否送审；可以先发 presubmission inquiry
- 地理遥感的顶刊故事常见四种讲法，见 `01-research-question.md` §4

## 3. 选刊流程

1. 定论文类型：时空变化、定量反演与模拟、观测对照（见 `16-paper-types.md`），或综述（交给 geo-review-writing）
2. 写出一句话贡献，判断主角是方法、数据产品还是地学认知
3. 按主角选组：方法 → A/B；地学认知 → C/D/H；数据产品 → E（ESSD）或 A；跨学科重大发现 → F
4. 读 aims & scope 和近 2–3 期目录，找 4 篇与本研究最接近的近作，作为反向工程的样本
5. 被拒后先诊断失败在哪一环：方法新颖性、验证设计、环境意义、尺度迁移、受众匹配，再决定转投哪里

## 4. 反向工程：用目标期刊校准写法

本 skill 给出的结构是起点，最终标准是目标期刊。取 4 篇目标期刊近 3–5 年、研究对象和手段相近的论文，统计：

- 各部分字数、段落数、子标题是名词短语还是句子
- 引言第一句有多具体，gap 用什么句式，是否以编号目标收尾
- 精度指标报哪几个、保留几位小数
- 结果与讨论是否合写（Catena、Geoderma 常见 Results and Discussion）
- 结论是一段还是编号要点
- 主动语态和 *we* 的使用频率

给每一句写一个功能描述（"在做什么"，而不是"在说什么"），2–3 篇之后，这本期刊的隐性规范就清楚了。
