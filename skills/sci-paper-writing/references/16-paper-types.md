# 16 · 三类研究论文的写法

本 skill 覆盖三类研究论文：时空变化、定量反演与模拟、观测对照。综述、系统综述、Meta 分析和文献计量交给 geo-review-writing skill。各类的完整讲解和案例见 `course-handout.md` 第二至四章。

## 1. 先判断属于哪一类

问一个问题："我的核心交付物是一张更准的图或一个更好的模型，还是一个变化故事及其归因，还是一个处理效应？"

| | 时空变化 | 定量反演与模拟 | 观测对照 |
|---|---|---|---|
| 回答的问题 | 怎么变、为什么变 | 怎么测得准、怎么模拟得好 | 处理是否有效、效应多大 |
| 证据来源 | 长时序遥感、站点 | 遥感 + 实测建模样本 | 一手观测或实验 |
| 审稿人盯 | 趋势显著性、驱动归因 | 精度验证、不确定性、可迁移性 | 对照、重复、随机化、伪重复 |
| 主要风险 | 相关当因果 | 黑箱、不可迁移 | 尺度局限、外推过度 |

很多论文两条腿都有（先反演、再分析变化）。此时选一条做主线组织全文，另一条降为方法或结果中的一节。两条线并列展开，是新手最常见的结构问题：反演论文套用变化类的讨论，讨论里只有"与前人异同"，没有误差来源分析；变化论文写完精度验证就收尾，没有驱动归因。

## 2. 时空变化类

**范式**：格局 → 过程 → 服务 → 调控

| 环节 | 焦点 | 常用方法 |
|---|---|---|
| 格局 | 分布、集聚、迁移、多尺度嵌套 | 热点分析（Getis-Ord Gi*）、标准差椭圆、Sen + MK 趋势 |
| 过程 | 自然–人文过程耦合、阈值与突变 | 地理探测器、SEM、GTWR、元胞自动机 |
| 服务 | 对产水、固碳等服务的影响及权衡协同 | InVEST、权衡协同分析 |
| 调控 | 空间优化、多情景路径 | 系统动力学、多目标优化 |

**写什么变化**：分布范围、分布界限、三维空间、形态格局、分布质心。

**怎么写透**：幅度（面积、等级、速率）、阶段（突变点、阶段划分）、趋势（斜率与显著性）、周期（振荡、持续性、滞后）、原因（驱动、交互、尺度）。

**加分项**：异常、突变、滞后、阈值、归因、预测。"基于 MODIS NDVI 分析某区植被变化，整体增加，降水和温度是主要因素"这类论文已严重同质化。

**自查**：
- [ ] 趋势给出斜率与显著性（Sen's slope + MK p 值）
- [ ] 有空间格局和面积比例
- [ ] 有阶段划分或突变点检验
- [ ] 驱动归因有方法支撑，相对贡献已量化，没有把相关写成因果
- [ ] 讨论了至少一项非平庸现象（异常、滞后、阈值、尺度依赖）
- [ ] 讨论了归因方法的假设与外推局限
- [ ] 结尾落到管理或调控含义

## 3. 定量反演与模拟类

**模型谱系**：

| 类型 | 特点 | 代表 |
|---|---|---|
| 物理模型 | 物理意义明确、可外推、复杂 | 辐射传输模型、SWAT、Hydrus |
| 统计模型 | 简单、外推有限 | 多元回归、克里金 |
| 机器学习 / 深度学习 | 捕捉非线性、黑箱 | RF、XGBoost、CNN |
| 混合模型 | 机理与数据驱动互补 | 物理约束的神经网络、ML 优化物理参数 |

**切入类型**：方法改进（特定条件下精度提升）、多源融合、时空拓展（历史重建、区域到全球）、应用导向（业务化）。

**写作注意**：模型选择要给理由；参数率定、超参数、阈值给具体数值；界定模型适用范围；与基线和已有产品比较。

**自查**：
- [ ] 模型选择有理由（为什么是它而不是替代方法）
- [ ] 参数、超参数给了具体数值；软件和库有版本号
- [ ] 验证方案明确，指标齐全（见 `04-validation-uncertainty.md`）
- [ ] 与基线、前人或单传感器方案做了比较
- [ ] 报告了不确定性
- [ ] 承认了至少一个具体局限（高值低估、饱和、混合像元、季节失配）
- [ ] 讨论了可迁移性；精度用词与数值匹配

## 4. 观测对照类

**设计铁律**：

1. 从可检验的假设出发，动手前了解研究对象的初始状态
2. 必须设置对照
3. 重复：用于估计误差；重复的层级必须落在施加处理的单元上（围栏、样地、流域），而不是测量次数上
4. 随机化：消除系统偏差

**伪重复**（Hurlbert, 1984）：把同一处理单元内的多次采样当作独立重复。一个围栏里测 10 株草，n 是 1 而不是 10。空间上相邻的样方存在自相关，也不构成独立重复。

**让观测研究写出"实验感"**：

- 把样地、站点、年份设为随机因子，用混合效应模型
- 沿环境梯度（海拔、降水、放牧强度）的观测借用"自然实验"的对比框架
- 时间上的政策突变（退耕还林、禁牧）可作为准实验处理
- 在方法里写明：对照是什么、混淆变量有哪些、如何控制

**结构要点**：

- 引言：从观测到的格局引出要检验的假说与预测
- 方法：处理与对照、水平数、重复数、随机化方案、采样时间与频率、统计方法
- 结果：按"处理 vs 对照"组织，报告效应大小和置信区间，而不只是 p 值
- 讨论：区分"观测到的关联"与"实验验证的因果"；写明外推边界（时间、地点、对象）
