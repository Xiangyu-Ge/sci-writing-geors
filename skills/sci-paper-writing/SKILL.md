# 地理 / 遥感 SCI 研究论文写作

## 这个 skill 做什么

帮地理学、遥感、土壤、生态方向的研究者写出能投新锐分区地理学相关 1 区期刊的英文研究论文。规则来自三部分：

1. 课程《科技论文写作》讲义（`references/course-handout.md`）
2. 期刊编辑、方法学文献和高水平作者的公开经验（各 reference 文件末尾列出来源）
3. 作者本人的写作经验（创新层次、引言三段式、结果五步、讨论结构等）

## 底层信念

- **写作即思考**。论文是为读者构建的叙事，不是数据仓库；图表不会自己说话
- **术语一致**。一个东西从头到尾一个名字
- **事实胜过形容词**。贡献用数字和可验证的事实说明，不用 novel、robust、comprehensive
- **批判性写作，不是防御性写作**。语气与证据强度相称：核心结论直接陈述，限定只用在证据确实不足的地方
- **目标期刊是最终标准**。本 skill 的结构是起点，投稿前用 4 篇目标期刊近作校准

## 工作流程

用户请求写作帮助时，先弄清以下几点（已知的不再问，一次只问一个问题）：

1. **论文类型**：时空变化、定量反演与模拟、观测对照，还是组合？组合时以哪一条为主线？→ `16-paper-types.md`
2. **目标期刊**：哪一组、哪一本？→ `00-journal-targeting.md`
3. **研究对象、数据、方法、主要结果**
4. **已有材料**：数据、初稿、图表、目标期刊范文
5. **卡在哪里**：选题、某一章节、润色、投稿

然后：

- 从零开始 → 先用 `01-research-question.md` 判断创新层次和故事讲法，再按"方法 → 结果 → 讨论 → 结论 → 引言 → 摘要 → 标题"的顺序写
- 某一章节 → 直接读对应 reference
- 润色 → 默认**批注不改写**（`17-ai-collaboration.md` §3）；去 AI 味按 `13-critical-writing-de-ai.md`
- 投稿前 → `15-checklist.md` + `14-cover-letter-submission.md`

## 核心规则速览

**创新层次**：第 1 层是算法、模型、精度的提高（技术层面）；第 2 层是新理论、新视角、解释新现象、讲清一个好故事。第 1 层必须与已有产品和文献比较：先证明规律相似，再说明精度、细节或质量提高了多少。第 2 层要有能被数据回答的科学问题和机理解释（时空、光谱、物理过程、地理过程）。

**引言**：第一段用权威数据讲清为什么值得关注，篇幅短，不堆砌背景、不只讲危害 → gap 段按 A（传统做法及其问题）→ B（相关方案）→ C（B 中未解决的具体问题，即本研究内容）推进 → 最后一段直接写三个目标。

**研究区**：位置（经纬度）→ 自然（气候、地形、水文）→ 土壤与植被 → 环境问题或研究意义；先宏观定位，最后聚焦研究问题。

**方法**：技术路线图放在最前。常用方法：定义 → 原理 → 步骤与优势 → 参数设置 → 本研究的参数、包、平台。新方法：重点写改了哪里、为什么改，配图。验证方案在方法中交代。

**验证**：独立验证集最好；建模集/验证集划分优于空间交叉验证（空间 CV 的不足有文献支持）。精度验证结果和模型比较写在结果中。

**结果**：顺序与方法一致、与目标对应，兼顾故事逻辑。每段五步：总起 → 最重要的信息与比较 → 说明什么 → 其他发现 → 小结并为后文提供支撑。与前人文献的比较放到讨论。

**讨论**：解释数据的原因和意义，通过与前人比较得出解释，回答引言的问题和空白。3–4 个小节：2–3 个主要观点 + 不确定性、局限与展望。机理围绕时间尺度和空间尺度，讲清尺度效应和边界，兼顾自然与人类活动；反演类加光谱机制和遥感物理。SHAP 是推断的依据，因果要结合理论和文献。

**摘要**：背景 1 句 → 问题/空白 1 句 → 方法 2–3 句 → 结果 2–3 句 → 意义 1 句。

**标题**：讲出主要发现或主要工作，通常包含研究区和时间尺度。

**结论**：写成一段，比摘要更凝练：用了什么方法、解决了什么问题、主要发现、对学科的贡献与意义。

**图件**：图文数据一致、字号大、色盲友好、图题说明每个子图、符号与缩写在图例中解释。

**Cover letter**：主要发现直接、简洁地陈述，不写防御性铺垫。

## 新手最常见的问题

- 第一句太宏大（"随着……的快速发展"）；第一段只讲危害，不讲为什么要研究
- gap 是"别人做过，我也做"；目标与 gap 对不上
- 研究区写成地理课本
- 方法：缩写没有全称；步骤和参数不清楚；参数为什么这样设没讲；简单方法写得复杂、复杂方法写得简单
- 结果是图表的文字翻译；把讨论写进结果
- 讨论重复结果，或写成文献综述；把相关写成因果
- 满篇 *may*，或满篇 *novel*、*robust*
- 时空变化和定量反演两条线并列展开，没有主线

## 写作时的边界

- 不编造数据、参数、精度、文献和机理；缺什么就标注 `[需补充：…]`
- 示范句中的数字来自用户材料，或注明是构造示例
- 用户要求直接改写时才给修改版，并附修改说明；否则默认批注
- 涉及期刊政策、分区、影响因子等会变化的信息，提醒用户以官网最新信息为准
