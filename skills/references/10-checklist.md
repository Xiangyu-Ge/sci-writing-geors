# 10 · 投稿前最终检查清单

这是写完一遍后的"过筛"工具。**逐项打勾,任何一项打不上勾就回去改**。本清单覆盖结构、语言、格式、伦理 4 大类共 100+ 项。

---

## A · 整体结构(15 项)

- [ ] 章节齐全:Title / Abstract / Introduction / Methods / Results / Discussion / Conclusion / References / (Acknowledgments / Funding / Author contributions / Data availability / Supplementary)
- [ ] 章节顺序符合目标期刊(有些期刊把 Methods 放最后)
- [ ] 各章节字数比例合理(摘要 < 5%、引言 ~10-15%、方法 ~15-30%、结果 ~20-30%、讨论 ~25-35%、结论 ~5%)
- [ ] **本研究的主要贡献(magnetic south)**在论文中**至少出现 3 次**:摘要、引言末尾、讨论结尾
- [ ] 引言与讨论**镜像对称**:引言里的每个 gap / question,在讨论里都有回应
- [ ] 摘要里提到的方法、结果,正文里**都能找到对应的详细版本**
- [ ] 摘要里的关键数字 / 关键发现,**结论里再次出现**
- [ ] 每个子节有清晰的子标题,**子标题风格一致**(都名词短语,或都句子,不要混搭)
- [ ] 没有"散段"(loose paragraphs)——每段都明确为某个论点服务
- [ ] 没有"散句"(loose sentences)——每句都为段落的核心功能服务
- [ ] 没有重复的内容(讨论里没有重复结果的论证,结论里没有重复讨论的细节)
- [ ] 图表数量合理(STEMM 通常 3-8 个),每个图表都被正文**至少引用一次**
- [ ] 图表按文中**首次提及**的顺序编号(Fig. 1, Fig. 2, ...)
- [ ] 引言**先于**方法 / 结果(显然,但有人在写作过程中乱套了)
- [ ] 投稿目标期刊的"作者须知"(Guide for Authors)**仔细读过一遍**,本文符合所有要求

---

## B · 标题与摘要(15 项)

### 标题

- [ ] 标题词数符合目标期刊均值(数 5-10 篇做参考)
- [ ] 最重要的关键词**放在前面**(SEO)
- [ ] 标题中**前 6 词**就能让读者识别本文主题
- [ ] 标题反映**研究产出**而非"研究过程"(不是 *A study on...*)
- [ ] 没有"working title"残留(*An investigation of, Some considerations on*)
- [ ] 标题类型(短语 / 冒号 / 句子)和目标期刊主流一致
- [ ] 复合名词链 ≤ 3 个名词
- [ ] 介词 ≤ 3 个,无歧义
- [ ] 缩写都是领域常识(否则展开)
- [ ] Happy words ≤ 2 个,且都是真实的
- [ ] 标题**不夸大**(论文确实兑现了承诺)
- [ ] **关键词列表**(单独提交的 5-8 个)和标题关键词**互补**,不完全重复

### 摘要

- [ ] 字数在目标期刊范围内
- [ ] **第一句**就传递具体信息,不是空泛背景
- [ ] 包含:背景 + 方法 + 结果 + 含义(4 要素)
- [ ] **方法 + 结果**部分不超过摘要 60%
- [ ] 包含 2-4 个 happy words(标记贡献)
- [ ] 关键数字 1-3 个(服务于价值判断)
- [ ] 缩写 ≤ 3 个新缩写,首次全称
- [ ] 几乎不引用文献(除非延伸自一个特定前作)
- [ ] 没有图、表、公式
- [ ] **独立成立**(剥离正文还能看懂)
- [ ] 时态使用让读者能分辨"是你做的"还是"是常识"
- [ ] **关键术语前后一致**,不混搭近义词
- [ ] 平均句长 < 25 词,无超长句
- [ ] 最后一句有 take-home / 应用 / 影响

---

## C · 引言(12 项)

- [ ] **第一句具体**,不是 *With the rapid development of...*
- [ ] **Block 1**(主题重要性 + 背景):占引言 30-40%
- [ ] **Block 2**(研究地图):覆盖与本文最相关的前人工作
- [ ] **Block 3**(空白):**显式声明**(可用 *however, little is known about, remains unclear*)
- [ ] **Block 4**(本文做什么):清晰、含 happy words
- [ ] 时态混合(背景:现在简单;前人工作:过去简单 / 现在完成;空白:现在完成;本文:现在简单 / 过去简单)
- [ ] 每段功能明确,段间用重复或代词衔接
- [ ] 关键引用文献数量合理(通常 20-40 篇),覆盖经典 + 近期
- [ ] 没有写成综述(只引用与本文论证直接相关的工作)
- [ ] 末段引出本文,有"happy words"标记贡献(*we present a novel..., to our knowledge, this is the first...*)
- [ ] 没有透露所有结果(可暗示主要结果,但细节留给后面)
- [ ] **引言读完,读者应该想知道"那他们做了什么"**——而不是"那然后呢?"

---

## D · 方法(15 项)

- [ ] 别人按这个方法能**复现**本研究
- [ ] 所有材料、试剂、设备**列出来源**(厂商、型号、城市 / 国家)
- [ ] 所有关键参数**有具体数值**(温度、压力、时间、浓度、转速...)
- [ ] 所有"被动语态"读者能分清"是你做的"还是"是引用的"——加 *here / in this study / in our protocol* 或主动
- [ ] 时态前后一致,切换时有理由
- [ ] 选择方法时**给了理由**(*due to its high sensitivity..., because it offers...*)
- [ ] 引用他人方法时**说清楚相同 / 相似 / 不同**
- [ ] 如有创新方法,**与已有方法的不同点**写得清楚
- [ ] **承认了至少 1 个**潜在问题 / 局限(主动 + 弱化)
- [ ] 统计方法 / 显著性检验明确(*p < 0.05, n = 25*)
- [ ] 实验组 / 对照组定义清楚
- [ ] 伦理批准(动物 / 人类实验)、IRB 编号都标注
- [ ] 重复实验次数明确(*in triplicate, n = 3 biological replicates*)
- [ ] 子节标题清晰,风格一致
- [ ] 段落长度合理(不超过半页)

---

## E · 结果(12 项)

- [ ] 子标题**信息量丰富**,扫一眼就能知道本节发现什么
- [ ] 每个图表**都被引用且讨论**,不只是"see Fig. 1"
- [ ] 关键结果有**评价语言**(*striking, only, as much as, as high as, dramatic*)
- [ ] 不是所有结果都写得同样详细——读者能看出"哪些是亮点"
- [ ] 用 *suggest / indicate* 等动词**预告了讨论**
- [ ] 没有把"长讨论"写到结果里(具体的机制解释、文献对比留给讨论)
- [ ] 时态使用合理(图表"显示"用现在简单;"我们观察到"用过去简单)
- [ ] **承认了至少一个**结果中的局限 / 问题
- [ ] 数字、单位、显著性标记前后一致
- [ ] **正面与负面发现**都呈现(没有报喜不报忧)
- [ ] **与现有研究做了对比**(in line with / in contrast to)
- [ ] 数据呈现合理:用图最好的用图,用表最好的用表,**不要图表互换**(同一数据图表里出现 2 次)

---

## F · 讨论(15 项)

- [ ] **不是简单重复结果**——重新组织 + 添加解读
- [ ] 引言里**每个 gap / question 都被回应**
- [ ] 主贡献(magnetic south)在讨论里**至少 2 次**显式声明
- [ ] 与至少 3 篇相关研究做**显式对比**(in line / in contrast)
- [ ] 语气强度**匹配**证据强度(不用 *prove* 除非真的证明了)
- [ ] **承认局限**:具体而非空洞(*A potential limitation is..., specifically...*)
- [ ] 未来工作**具体可行**(不是 *more research is needed*)
- [ ] 给出**实际应用**或**领域影响**
- [ ] 没有引入新的、未在前面讨论过的内容(摘要 / 引言里没暗示过的)
- [ ] 没有把讨论写成"再讲一遍结果"
- [ ] 模态动词使用合理(*may, might, could, would* 等匹配信心度)
- [ ] **机理推测**有明确标记(*we speculate that..., it is tempting to suggest...*)
- [ ] 每段功能清晰(一段一个核心论点)
- [ ] 用 happy words(节制),不堆叠
- [ ] **结尾段**有强力收尾(贡献声明 / 应用前景 / 大背景呼应)

---

## G · 结论(8 项)

- [ ] 字数符合目标期刊惯例(通常 100-200 词)
- [ ] **没有重复**讨论的具体论证细节
- [ ] take-home message 在**前两句**就出现
- [ ] 用了 happy words(节制)
- [ ] 没有引入新内容
- [ ] 有明确的"未来方向"或"应用前景"
- [ ] 最后一句**有力**(不是 *More research is needed*)
- [ ] **独立成立**(剥离开论文后,读者还能看懂)

---

## H · 语言精度(15 项)

- [ ] **平均句长 20-26 词**;没有连续 3 句以上的长句(> 30 词)
- [ ] **平均段落 150-170 词**;没有单句段或全页段
- [ ] **句子起始**:用重复关键词、代词短语、信号词衔接上下文
- [ ] **It / This / These** 后面都跟具体名词,或上文指代明确
- [ ] **时态切换**:每次都有意义,不是随手换
- [ ] **被动语态**:无歧义地标识"是谁做的"
- [ ] **关键术语前后一致**(method / approach / framework 不混用)
- [ ] **冠词** *a / the / ∅* 选择无错
- [ ] **介词搭配**符合学术习惯(Google Scholar 验证过)
- [ ] **副词位置**(*only, just*)修饰对象明确
- [ ] **没有空洞修饰词**(*basically, very, obviously, clearly*)
- [ ] **没有 -ing 歧义**(必要时改为 *by / when / which* 子句)
- [ ] **弱动词**(get, have, make, do)替换为具体动词
- [ ] **没有中式英文残留**(列在 `09-grammar-style.md` §15)
- [ ] **拼写、大小写、连字符**前后一致(每个术语统一用同一形式)

---

## I · 图表(12 项)

- [ ] 每个图都有**编号 + 标题 + 图例**
- [ ] 图标题**完整描述图内容**(读图不读正文也能基本看懂)
- [ ] 表用 3 横线(top / heading-bottom / bottom),无竖线(多数期刊要求)
- [ ] 字体、字号、颜色方案、轴标签、单位**前后一致**
- [ ] 所有缩写在**第一次出现的图 / 表的图例里**展开
- [ ] 误差棒标注(SD / SEM)
- [ ] 显著性标记一致(*, **, ***, n.s.;并在图例说明含义)
- [ ] 像素 / 分辨率符合期刊要求(通常 300+ DPI)
- [ ] 颜色考虑色盲友好(避免红绿对比)
- [ ] 不重复(同一数据不在图和表里各出现一次)
- [ ] 引用其他文献的图,**有版权许可**
- [ ] 补充材料(SI)里的图表标号前缀正确(Fig. S1, Table S1)

---

## J · 引用与参考文献(10 项)

- [ ] 引用格式符合期刊要求(Vancouver / APA / Author-year ...)
- [ ] **每个引用都在正文中至少出现一次**,反之每个文中引用都有列表项
- [ ] **引用位置准确**:句末或被引论点附近,避免堆叠在段尾
- [ ] **不要把所有引用堆在一处**(*[1-15]*)——具体到哪个文献支持哪个论点
- [ ] **直接引用 quotation**(整句逐字)非常罕见——重写为自己的话 + 引用即可
- [ ] **避免自引过度**(超过总引用数 20% 即引起审稿人警觉)
- [ ] **近期引用比例**:1/3 以上来自近 3-5 年(显示前沿性)
- [ ] **预印本与会议论文**标注清楚(arXiv, bioRxiv, IEEE conference vs journal)
- [ ] **DOI 全部填写**(多数期刊要求)
- [ ] **没有缺失引用**(每个"前人发现了 X"的论断都有引用)

---

## K · 元数据与提交材料(10 项)

- [ ] **作者顺序**与所有合著者确认无误
- [ ] **通讯作者**邮箱、单位有效
- [ ] **作者贡献(CRediT)**写好(每个作者具体做了什么)
- [ ] **利益冲突声明**(无 → "The authors declare no competing interests.")
- [ ] **基金来源**(项目编号、机构名称)
- [ ] **致谢部分**:感谢非作者贡献者(技术支持、读稿)
- [ ] **数据可得性声明**(Data Availability Statement)
- [ ] **代码可得性**(如适用,提供 GitHub / Zenodo 链接)
- [ ] **伦理 / IRB / 动物 / 知情同意**声明(如适用)
- [ ] **Cover letter**:简洁说明本文意义、为何适合该期刊、未同时投稿等

---

## L · 投稿前自测题(5 道)

让用户回答这 5 题,如果哪题答不出 → 论文还没准备好。

1. **本文的 take-home message 用一句话怎么说?**(< 30 词)
2. **本文最大的贡献是:方法 / 结果 / 理论 / 应用?**(选一个,不要"全部")
3. **审稿人会问的第 1 个问题是什么?**(预先准备回答)
4. **本文最弱的地方是什么?**(自知之明,留好回应)
5. **3 年后这篇论文还会被读 / 引用吗?为什么?**(超越短期的视角)

---

## M · 投稿后

虽然超出本技能范围,但顺带提一下:

- [ ] 收到 minor / major revision 时,**逐条回应**(Response to Reviewers 文件)
- [ ] 不同意审稿人意见时,**礼貌坚持**,给出具体证据 / 文献
- [ ] 同意修改时,**指出文中具体修改位置**(*pp. 5, lines 23-28*)
- [ ] Cover letter to editor:简短说明主要修改

## 用法建议

不要一次性看完整张清单——会麻木。

**正确用法**:
1. 论文写完一遍后,选**最相关的 3-4 节**(比如刚写完讨论 → 查 F 和 H)
2. 一项一项打勾,**任何一项没勾**就回去改
3. 改完后,**整篇通读一次**,再用 L 节的 5 道题测试
4. 全部过关再投稿

**Hilary Glasman-Deal 的最后一句忠告**(译):

> 无论你要写什么文档,**用本书的方法,对一些最近发表的范例进行反向工程**——这会生成一个稳健可靠的模型。

把这条作为终身写作策略,而不只是这一篇论文。SCI 写作规范在变,反向工程不会过时。

## ★ N · 地理 / 遥感专属检查项

> 通用清单(A–M)之外,本领域两类论文必查。

### N1 · 研究区(Study Area)
- [ ] 按 **位置 → 自然 → 人文 → 科学意义** 漏斗组织
- [ ] 给了经纬度范围、总面积、行政/地理单元
- [ ] 气候(年均温、年降水、蒸发)、地形(高程)、水文、主要土壤类型(注明分类体系 WRB/USDA)、植被/土地利用
- [ ] **末句收敛到研究问题**(如"prone to salinization, an ideal site for...")
- [ ] 有 location map(含采样点/DEM/底图),正文引用
- [ ] 没有写成"地理课本"——无关要素已删

### N2 · 数据(Data)
- [ ] 分 **实测** 与 **遥感+辅助** 两类
- [ ] 遥感:传感器名、获取时间、空间分辨率、波段/光谱分辨率、产品级别、预处理(大气/几何校正、去云、滤波)、获取平台
- [ ] 实测:采样时间(是否与过境同步)、样点数、布设方式、仪器型号、测量参数与方法、训练/验证划分
- [ ] 辅助:DEM/LULC/气象 的来源、分辨率、时段
- [ ] 有数据汇总表,正文引用
- [ ] 关键软件/库**标了版本号**(可复现)

### N3 · 方法(Methods)
- [ ] 每个核心算法按 **是什么/原理/步骤/优势/本研究参数/平台与包版本** 写
- [ ] 引用前人方法/指数时说清相同/相似/不同
- [ ] 反演:变量筛选方法、建模算法、验证方式、精度指标都交代
- [ ] 变化:长时序构建、趋势方法(Sen+MK)、显著性、变化检测、**驱动归因方法** 都交代
- [ ] 承认至少一个数据/方法局限并合理弱化

### N4 · 反演结果与精度
- [ ] 报告了 **R² + 误差(RMSE/MAE)+ 验证方式(CV/独立集)**,缺一不可
- [ ] 与基线/前人/单传感器做了对比
- [ ] 精度词与数值匹配(0.5 的 R² 不说 excellent)
- [ ] 有空间制图 + 误差/不确定性的空间或区间描述
- [ ] 报喜也报忧(高值低估、饱和、混淆都说)

### N5 · 时空变化结果与归因
- [ ] 报告了总体趋势(斜率 + 显著性 p)+ 空间格局/热点 + 速率分级(面积%)
- [ ] **没把相关说成因果**——归因有方法支撑(残差趋势/地理探测器),表述用确定性阶梯
- [ ] 给了气候 vs 人类活动的相对贡献(若做归因)
- [ ] 讨论了外推局限与归因方法的假设

### N6 · 单位与符号一致性
- [ ] 数值有单位;时段用 en dash(2000–2022);数字与单位间空格(10 m)
- [ ] R² 小数位、p 值写法全文统一
- [ ] 术语全文一致(soil salinity / Sentinel-2 imagery 不漂移)

### N7 · Cover Letter(见 `11-cover-letter.md`)
- [ ] 含:题目 + 为何适合该期刊 + 做了什么 + 亮点 + 致谢
- [ ] 声明:原创、未一稿多投、所有作者同意
- [ ] 一页以内,贡献用 1-3 句讲清,亮点 2-4 条
- [ ] 期刊名、主编称呼、稿件类型正确
