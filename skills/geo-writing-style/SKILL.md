# 个人写作风格档案

风格档案是一组规则约束，不是对作者声音的完整复制：用了它，产出会更好、更接近作者，但不会和本人完全一样。它需要持续迭代。

## 1. 建档流程

### 第一步：收集样本

请用户提供 3–5 篇自己满意的写作：已发表论文（含合著）、基金书、邮件、博客都可以，条件是作者觉得"这确实像我写的"。样本越多、文体越接近目标用途越好。只用英文论文建英文论文的档案；中文写作另建一份。

### 第二步：按六类分析

逐篇阅读样本（不只看摘要），按以下六类归纳，每条规则都配 1–2 个样本原句作为证据：

| 类别 | 要归纳的内容 |
|---|---|
| 1 句子长度 | 平均句长、长短句如何搭配、何时用短句 |
| 2 语气 | 结论强度、限定词的使用频率与位置、是否用 *we*、主动与被动的比例 |
| 3 用词 | 高频动词与名词、偏好的术语、常用的衔接方式（重复关键词、代词、信号词） |
| 4 结构 | 段落如何开头和收尾；引言、结果、讨论各节的开头方式；是否用编号目标、信息型子标题 |
| 5 一贯的做法 | 总是会做的事（例：精度先报 R² 再报 RMSE；讨论每段先给观点句；数字后紧跟单位和显著性） |
| 6 从来不做的事 | 作者从不使用的词、句式和结构（例：从不用 *With the rapid development of…* 开头；从不用 novel；从不以 *further research is needed* 收尾） |

### 第三步：整理成档案并请作者审核

按 `references/style-profile-template.md` 的格式输出一份 `writing_style.md`。分析结果只是起点：

- 请作者删掉分析错的规则，补上遗漏的，把模糊的规则写具体
- 对样本里的"怪癖"，问作者这是想保留的风格，还是想改掉的习惯
- 不写恭维性的总结（"作者文风严谨、逻辑清晰"之类）；每条都要是能执行的规则

### 第四步：保存

档案由作者保存。建议把审核后的 `writing_style.md` 放进本 skill 的 `references/` 目录，替换模板，之后每次调用都会读取它。也可以按文体分多份：论文一份、基金书一份、中文期刊一份。

## 2. 使用档案

### 起草

先读 `references/writing_style.md`（若存在），按其中的六类规则起草。"从来不做的事"一栏优先级最高。没有档案时，提醒用户可以先建档，并按 sci-paper-writing skill 的默认规则起草。

### 润色：默认批注，不改写

1. 原文保持不动
2. 在偏离档案规则、论证不清或有 AI 腔的地方插入批注，写明问题、对应的是哪条规则
3. 作者自己决定重写、删除或保留

用户明确要求直接修改时，才给出修改版，并逐条列出修改说明。

### 检查是否"像本人"

对照档案逐类检查：句长分布、限定词频率、*we* 的使用、段落开头方式、有没有出现"从来不做的事"。

## 3. 迭代

- 每次用户修改了起草稿、或说"这不像我"，就是档案漏掉了什么：问清楚差在哪，提议补一条规则
- 用户纠正同一类问题两次以上时，提议把它写进档案
- 档案是活文件；定期（如每完成一篇论文）用新论文补充样本

## 4. 边界

- 风格档案只管表达方式，不改变论文的事实、数据、结论强度与证据之间的匹配
- 档案中的规则不能要求隐瞒局限、省略必要的限定，或违背期刊的 AI 使用声明要求
- 与 sci-paper-writing skill 的去 AI 味规则冲突时：作者档案里明确保留的习惯（如偏爱破折号）优先，但仍控制频率
