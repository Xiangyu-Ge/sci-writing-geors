# 回复审稿意见的英文句式

## 开头（全文一次）

```
We thank the Editor and the reviewers for their careful reading of our manuscript and for their constructive comments.
We have revised the manuscript accordingly. Below, the reviewers' comments are shown in italics, followed by our responses. Changes in the manuscript are highlighted in the marked-up version.
```

## 致谢（只用于重要意见）

```
We thank the reviewer for this important point.
This is a helpful suggestion, and we have followed it.
```

## 同意并修改

```
We agree and have revised the text accordingly (Page X, Lines Y–Z).
As suggested, we have added... The results are shown in new Figure X.
We have rephrased the sentence to avoid ambiguity: "..."
Corrected as suggested.
```

## 补充了分析

```
Following the reviewer's suggestion, we performed an additional analysis using...
The results (new Table X) show that..., which supports / does not change our main conclusion.
```

## 解释与反驳

```
We understand the reviewer's concern regarding... However, in the context of our study,...
We respectfully note that... (refs). To avoid similar misunderstanding, we have clarified... in Section X.
This choice follows established practice in... (refs).
We have retained... because..., and we now explain this choice in the Methods (Page X, Lines Y–Z).
```

## 无法满足

```
We agree that... would strengthen the study. However,... was not feasible because...
Previous studies have shown that... (refs), which suggests that... is unlikely to change our conclusions.
We have acknowledged this limitation in Section X (Page X, Lines Y–Z).
```

## 审稿人之间意见冲突（写给编辑）

```
Reviewers 1 and 2 made different recommendations regarding... We followed Reviewer 1's suggestion because..., and we explain in our response to Reviewer 2 why... (refs).
```

## 语言润色

```
The manuscript has been edited for language by a native English speaker / a professional editing service.
```

## 修回 cover letter

```
We thank the Editor and reviewers for their constructive comments. We have carefully revised the manuscript; a point-by-point response is provided separately. The main changes are: (1)...; (2)...; (3).... All revisions are highlighted in the marked-up manuscript.
```
