# 地理 / 遥感综述与 Meta 分析写作

完整的方法讲解、案例和工具对比见 `references/review-methods.md`。语言层面的规则（去 AI 味、批判性写作、时态、衔接）沿用 sci-paper-writing skill 的 `13-critical-writing-de-ai.md` 和 `12-grammar-style.md`。

## 1. 先定综述类型

| 类型 | 特征 | 回答的问题 | 典型题目 |
|---|---|---|---|
| 一般性综述 | 专家经验驱动，按主题或时间组织 | 这个领域有哪些进展、空白和方向 | X 在 Y 中的应用研究进展 |
| 系统综述 | 明确的检索与纳入/排除标准，流程透明可复现 | 现有高质量证据怎么说 | X 对 Y 影响的系统综述 |
| Meta 分析 | 系统综述 + 效应量的统计合并 | 综合效应多大，异质性从哪来 | X 特性对 Y 影响的 Meta 分析 |
| 文献计量综述 | 算法与可视化驱动，大样本 | 知识结构、演化、热点与前沿 | 基于 CiteSpace 的 X 研究现状与趋势 |

不确定时问用户：核心交付物是"领域进展的判断"、"证据的综合结论"、"一个合并效应量"，还是"知识图谱与演化路径"？

## 2. 工作流程

### 2.1 问题与检索（系统综述、Meta 分析）

1. 用 **PICO(T)** 把想法变成可检索的问题：P 研究对象，I 干预或指标，C 对照，O 结果，T 时间范围
2. PICO 的每个要素对应检索式的一个 AND 块，同义词放进 OR 块
3. 在目标数据库试跑，记录命中数，人工抽查前 50 条；结果太多就收紧 P 或加 T，太少就放宽 I 的同义词。很多地理生态研究本来没有严格对照，强行要求 C 会漏掉大量合格文献
4. 至少用两个数据库（如 WoS + Scopus），中文主题加 CNKI；写明每个库的完整检索式、检索日期和命中数

### 2.2 筛选与证据表

- 去重 → 摘要初筛 → 全文复筛 → 纳入；每篇排除的文献写一句理由，PRISMA 流程图的"排除原因"靠它
- 双人独立筛选与提取，核对一致性
- 证据表统一字段：作者、年份、研究区、方法、效应量及其方差、质量评分
- Zotero 可按"原始导入 / 摘要初筛 / 全文复筛 / 纳入证据表 / 排除但需引用 / 方法记录"建集合，用 PICO、方法、状态三层标签

### 2.3 Meta 分析的统计

- **效应量**：处理 vs 对照的连续变量用 lnRR（可换算为百分比变化）或 Hedges' d；相关系数先做 Fisher z 变换；二分类结局用 OR/RR
- **模型**：默认随机效应模型；同一研究贡献多个效应量时用多水平模型（`metafor::rma.mv()`，研究 ID 设为随机因子），不要当独立样本
- **异质性**：报告 I² 与 Q 检验；用亚组分析和 Meta 回归解释来源。地理生态 Meta 分析里，高异质性往往是论文的第二个发现：把调节变量（纬度、气候带、干扰强度）提升为独立小节
- **稳健性**：标准化残差 > 2 为疑似异常值，hat 值 > 2 倍均值为强影响点，逐个剔除后看结论是否翻转；发表偏倚用漏斗图 + Egger 回归 + 失安全数
- 计算交给 metafor 等统计软件；模型结构由作者根据数据依赖关系决定

### 2.4 文献计量

- 数据源优先 WoS 核心合集；混库前先对齐字段
- 关键词同义词、单复数、缩写在清洗阶段合并
- 必须报告：数据来源与检索式、时间跨度、Time Slicing、Top N 等参数
- 图谱是参数过滤后的视觉表征，不是领域全貌；作者的核心贡献是解释"为什么"，例如为什么某方法在某时期突现
- 常见组合：VOSviewer（聚类与合作网络）+ CiteSpace（突现与时间线）+ biblioshiny（描述性统计）

## 3. 写作结构

**系统综述 / Meta 分析**：结构化摘要 → 引言（背景、研究问题与目标、为什么需要这篇综述）→ 方法（检索策略、纳入排除标准、PRISMA 流程图、数据提取、质量评估、统计模型）→ 结果 → 讨论（解释与意义、与已有综述比较、局限、建议）→ 结论 → 附录（完整检索式、纳入研究列表、证据表）

**Meta 分析结果段的顺序**：总体结果 → 异质性解释 → 敏感性验证 → 发表偏倚 → 证据等级。

> *A total of k studies (n = … observations) met the inclusion criteria. The overall effect of X on Y was positive (lnRR = …, 95% CI: …–…). Heterogeneity was substantial (I² = …%) and was partly explained by latitude (meta-regression: β = …, p = …). The pooled estimate was unchanged after removing influential cases. Egger's regression indicated no publication bias (p = …).*

**一般性综述**：引言（背景、意义、目的）→ 主体（按主题或时间，从宏观到微观、从基础到前沿）→ 讨论（差距、争议、方向）→ 结论。

**文献计量 / 混合型综述**（参考 Geoderma 数字土壤制图综述）：引言（挑战背景 → 领域定义 → 完整检索式）→ 现状与趋势（发文、空间分布、对象、协变量、模型谱系、验证与不确定性）→ 挑战与前景 → 编号列出可操作的建议。

## 4. 核心规则

- **综而有述**：不罗列文献，要分类、总结、评论，并建立文献与作者立场之间的关联
- 每个小论点尽量有 3 篇以上可靠文献支撑；引用忠于原文，区分作者观点与文献内容
- 写明"为什么需要这篇综述"：结果不一致、缺少综合评估、上一篇综述已过时
- 结论逐条指出缺什么、错什么、下一步做什么；不写"研究越来越多"这类空话
- 图谱、森林图、漏斗图的图例、缩写、单位、坐标齐全

## 5. AI 的边界

可交给 AI：拆解 PICO(T)、生成检索式初稿、按标准初筛摘要、按字段结构化提取信息、写 R 代码。

每一环都要人工把关：

- 检索式在数据库里试跑并迭代 2–3 轮
- AI 初筛后人工抽样复核至少 10%，边界文献人工裁决；筛选标准改动要记录版本
- AI 提取的每个数字回原文核对；进入证据表前核验文献类型（排除被误当作原始研究的综述、评论）
- 质量评估、异质性的机制解释、判断哪些结论是证据支持的，由作者完成

本 skill 不编造文献、效应量或检索结果；缺少的信息标注 `[需补充：…]`。

## 6. 自查清单

- [ ] 综述有明确的研究问题（PICO），不是泛泛的"研究进展"
- [ ] 检索策略完整可复现：数据库、检索式、日期、筛选标准
- [ ] 有 PRISMA 流程图，排除阶段写明原因
- [ ] Meta 分析报告了效应量类型、模型结构、质量评估、异质性、敏感性分析与发表偏倚
- [ ] 文献计量报告了 Time Slicing、Top N 等关键参数，并解释了机制
- [ ] 讨论有作者自己的评价、机制解释与未来方向
- [ ] 每个论断有文献支撑且忠于原文
- [ ] 图表图例、缩写、单位、坐标齐全
