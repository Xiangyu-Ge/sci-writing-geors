# 第一章 综述类论文写作（文献计量 / CiteSpace、系统综述、Meta 分析）

## 1.1 综述家族的"同心圆"：四类综述的边界

以"生物炭"主题为例看三类综述的进化：

| 类型 | 典型题目 | 特征 | 一句话概括 |
|---|---|---|---|
| 一般性综述（叙述性综述） | 生物炭在农业中的应用研究进展 | 泛泛而谈、陈列文献；专家经验驱动 | 提供主题的广泛概述 |
| 系统综述（Systematic Review） | 生物炭对作物产量影响的研究进展 | 有文献标准、聚焦问题；明确纳入/排除标准 | 用严格系统的方法识别、评估、综合全部高质量证据 |
| Meta 分析（荟萃分析） | 生物炭特性对作物产量影响的 Meta 分析 | 定量分析、聚焦关系 | 系统综述的特殊形式，对多项研究的定量结果做统计合并，给出综合效应量 |
| 文献计量综述（Bibliometric Review） | 基于 CiteSpace 的陆地生态系统碳汇研究现状及趋势 | 定量客观分析、大数据模式挖掘、算法与可视化驱动 | 用数学与统计方法定量分析知识载体 |

**传统综述 vs 文献计量**：定性主观 vs 定量客观；小样本深读 vs 大数据挖掘；依赖专家知识 vs 依赖算法与可视化；前者结论有深度，后者能发现隐藏关联（如知识跨学科传播、理论的真实影响力）。

**为什么需要计量与 Meta 方法**：面对数万篇文献，人工阅读效率低下；个人偏好带来主观性；宏观尺度上环境异质性导致各地研究结论冲突（地理空间的"各执一词"），分散的研究无法直接比较——系统综述与 Meta 分析正是为解决"结论矛盾"而生。

## 1.2 一般性综述：结构与写作要点

**结构**：题目 → 摘要 → 引言（研究背景、意义和目的）→ 主体（按主题或时间逻辑组织：关键概念与定义、研究现状、重要理论与方法、主要发现与贡献、研究趋势）→ 讨论（研究差距、争议问题、未来方向）→ 结论 → 参考文献。

**写作要点**：提供广泛概述、建立研究背景；归纳现有知识体系；确定热点与趋势；指出差距与未来方向；体现作者的专业见解。**必须避免"综而不述、述而不引"**——综述不是文献罗列，要对文献分类、总结、评论，并建立文献与自己研究立场之间的关联；每个小论点的论据尽量有 3 篇及以上支撑，优先引用代表性强、可靠性高的文献；引用必须忠于原文内容。

**组织逻辑**：通常按主题逻辑或时间逻辑，从宏观到微观、从基础到前沿。

## 1.3 系统综述：PRISMA 与 PICO 双框架

### 1.3.1 PRISMA 指南

PRISMA（Preferred Reporting Items for Systematic Reviews and Meta-Analyses，《系统综述和荟萃分析优先报告条目》）是提升系统综述科学性与可比性的黄金标准，核心交付物是 **PRISMA 检查表**与 **PRISMA 流程图**（"检索—筛选—纳入"漏斗：记录各阶段识别、去重、排除、纳入的文献数量及排除原因）。PRISMA 2020 共 27 条规范，强调流程透明、报告完整、方法可复制；生态与演化生物学领域还有专门扩展 **PRISMA-EcoEvo**（O'Dea et al., 2021），要求报告模型结构（响应变量、预测变量、交互作用）、纳入研究须在正文正确引用（而非仅列于附录），并建议预注册（pre-registration）综述方案。

### 1.3.2 PICO(T) 框架：把宽泛想法变成可检索的问题

- **P（Population/Problem）**：研究对象，如"森林"
- **I（Intervention/Indicator）**：干预措施或指标，如"无人机遥感"
- **C（Comparison）**：对照，如"传统地面调查"
- **O（Outcome）**：结果，如"病虫害监测精度"
- **(T)（Timeframe）**：时间范围，如"过去五年"

**实战示范（地理/生态版）**：宽泛想法"无人机遥感对生态监测有用吗"无法直接检索；PICO 化之后——P=温带森林病虫害监测；I=无人机多光谱遥感；C=传统地面样方调查；O=监测精度（总体精度 / Kappa）与成本；T=2015 年至今——检索式随之自然生成：*("UAV" OR "drone" OR "unmanned aerial vehicle") AND ("forest") AND ("pest" OR "disease" OR "infestation") AND ("detection accuracy")*。**PICO 的每个要素对应检索式的一个 AND 块，同义词进 OR 块**——这就是"想法 → 问题 → 检索式"的转换链。

**社区经验**（高浏览量方法博客的共识）：PICO 不是一次性填完的表格，而是**检索式的调试器**——初检结果太多（上万条），收紧 P（限定类群/区域）或加上 T；结果太少（几十条），放宽 I 的同义词，或者干脆去掉 C——**很多生态与地理研究本来就没有严格对照，强行要求 C 会误杀大量合格文献**。写方法时把最终版 PICO 与检索式一起报告，审稿人据此判断你的检索是否可复现。

**系统综述必要性声明**：解释为何需要本综述（现有结果不一致、缺乏综合性评估、上一篇综述已过时十年等）——这是引言的落脚点，也是 Cover Letter 里回答"为什么是这篇综述"的弹药。

### 1.3.3 系统综述的完整结构

标题 → 结构化摘要 → 引言（背景、研究问题与目标、综述必要性）→ 方法（检索策略：数据库、关键词、时间范围；纳入与排除标准；PRISMA 筛选流程图；数据提取方法；质量评估方法）→ 结果（纳入研究特征、质量评估结果、主要发现综合）→ 讨论（结果解释与意义、与已有研究比较、局限性、未来建议）→ 结论 → 参考文献 → 附录（完整检索式、纳入研究列表、数据提取表）。

**各阶段的过程交付物**（边做边留痕，写方法时直接引用自己的记录）：

| 阶段 | 交付物 | 常见疏漏 |
|---|---|---|
| 检索 | 每个数据库的完整检索式 + 检索日期 + 命中数存档 | 只写"检索了 WoS"不给检索式 |
| 去重与初筛 | 题录库（去重后总数）、摘要初筛的排除原因分类 | 排除不写原因，PRISMA 流程图画不出来 |
| 全文复筛 | 逐篇纳/排决定 + 理由笔记 | 凭印象筛，事后无法复盘 |
| 纳入与提取 | 证据表（作者/年份/区域/方法/效应量/质量评分） | 边看边记没有统一字段，后期返工 |

**Zotero 落地工作流**（社区系统综述实操方案，可直接照搬）：按流程建六个集合——`01原始导入 / 02摘要初筛 / 03全文复筛 / 04纳入证据表 / 05排除但需引用 / 99方法记录`；标签分三层——**PICO 标签**（如 `P:森林`、`I:UAV`）、**方法标签**（如 `M:RCT`、`M:观测`）、**状态标签**（`待筛 / 摘要纳入 / 全文排除 / 最终纳入`）；每篇排除的文献在笔记里写一句纳排理由——写 PRISMA 流程图的"排除原因"栏时全靠它。

**三类必须主动管理的风险**：① **检索偏倚**——单一数据库≠全部证据（医学综述只查 PubMed、地学综述只查 WoS 都会系统性漏掉区域期刊与非英文文献），至少两个数据库互补并在局限性里交代覆盖边界；② **自动化误差**——题录自动抓取可能缺 DOI、把评论/社论误当原始研究，**引用前必须回原文核验**；③ **证据过度解释**——纳入研究本身的偏倚会原样传导进你的综合结论，质量评估低的研究要在结果里降权或单独讨论。

**写作要点**：用 PICO 明确定义研究问题；详细说明检索与筛选过程；确保方法透明可重复；严格评估纳入研究质量；整合证据避免偏见；明确指出局限性。

## 1.4 Meta 分析：定量综合的"三板斧"与写作要点

### 1.4.1 核心思想

把不同地区、不同团队结论矛盾的研究，提取可量化的**效应量**（如相关系数 r、标准回归系数、OR/RR/SMD 等），通过统计模型（固定效应或随机效应）合并出综合效应，并检验异质性与发表偏倚。课程案例（IF 8.3 期刊，气象因素与 COVID-19 传播的 Meta 分析）的数据提取字段可供参考：文章标题、第一作者、发表时间、研究周期与长度、研究区域、**地理纬度**（用 Google Earth 获取）、气象因素及其与结果的相关系数。

**效应量怎么选**（方向不同，首选不同，选错会被审稿人直接打回）：

| 领域/数据类型 | 首选效应量 | 说明 |
|---|---|---|
| 生态学实验（处理 vs 对照，连续变量） | **lnRR（反应比）** 或 Hedges' d | lnRR 不含方差项，不受研究设计与类群方差差异的混杂（Spake & Doncaster, 2017），可直接换算成百分比变化：(e^lnRR − 1) × 100%；部分文献不报方差也能纳入。Hedges' d 在低重复、高异质性（生态学常态）下有偏（Hamman et al., 2018, *Ecosphere*），用 d 须论证合理性 |
| 相关系数类（如气候因子 vs 传播率） | **Fisher z 转换** | r 先做 Fisher z 变换再合并，报告时再反变换回 r |
| 医学/流行病学（二分类结局） | OR / RR | 计量类（连续结局）用 MD（同单位）或 SMD（不同单位） |

**统计模型的选择**：生态与地理 Meta 分析默认用随机效应模型（或多水平模型），因为不同研究区、不同年份之间本来就存在真实异质性；I² 与 Q 检验用于描述和报告异质性大小，不作为切换固定/随机效应的开关。只有在纳入研究确实同质（同一设计、同一类群、同一区域）且研究目标只针对这些研究本身时，才考虑固定效应。异质性来源用亚组分析、Meta 回归和敏感性分析去解释。**生态与地理数据的特殊坑**：同一研究常贡献多个效应量（多时间点、多处理组、多指标），彼此不独立——用 `metafor::rma.mv()` 多水平模型，把研究 ID（必要时加物种 ID）设为随机因子控制数据依赖，而不是当作独立样本直接 `rma.uni()`。

**数据提取的两件顺手工器**：① R 包 **metafor**——`escalc()` 统一计算效应量与方差，`rma.uni()` 单水平合并，`rma.mv()` 多水平合并，森林图/漏斗图/Egger 检验一站出齐；② **WebPlotDigitizer**——老文献只给图不给数时，从已发表的图上把数据点抠出来（标注清楚哪些数据是图提取的，并做双人交叉核对）。

### 1.4.2 图表"三板斧"识读

**① 森林图（Forest Plot）——总体效应**
- 用途：把多个维度的影响综合起来，分辨哪个因素真起作用、哪个只是统计巧合。
- 识图：中央竖线为无效线（刻度 0）；黑块=效应大小（标准化系数）；横线=置信区间。**横线跨过 0 线即统计学上不显著**；完全落在 0 线一侧才显著。黑块在 0 左侧为负向（抑制）效应，右侧为正向（促进）效应。
- 例：Spatial scale 的横线跨过 0 → 空间尺度影响不显著；Season、Latitude 的横线不跨 0 → 有显著调节作用。

**② 漏斗图（Funnel Plot）——发表偏倚**
- 背景："好结果容易发表，无效结果锁进抽屉"是学界潜规则，导致发表偏倚。
- 识图：横轴=效应量，纵轴=标准误（越往上误差越小、样本量越大）；点沿中心轴大致对称→无明显发表偏倚；明显缺角→有数据被"藏起来"。虚线=合并效应量；斜线边界通常代表 95% 置信区间，超出边界提示高异质性。

**③ 异质性检验与 Meta 回归——寻找矛盾背后的规律**
- 异质性：I² > 50% 且 p < 0.01 表明各研究效应差异显著——**对生态与地理研究，结论矛盾不是坏事，说明背后藏着空间规律**。
- Meta 回归：带趋势线的散点图（如横轴=纬度，纵轴=效应量 COR）；趋势线倾斜且 p 足够小（<0.05 或 <0.1）说明该地理变量确实影响结论。例：日最高气温的促进效应随纬度增加而增强，相对湿度的抑制作用也随纬度增强——机制解释（高纬度冬季寒冷、飞沫沉降等）必须由研究者基于专业知识给出。

### 1.4.3 Meta 分析结果段的推荐叙述顺序

按"**总体结果 → 异质性解释 → 敏感性验证 → 偏倚评估 → 证据等级**"组织证据，而不是把表格逐条复述。结果写作要短句、直述、可复核：写清纳入研究数量、样本量总和、合并效应量与置信区间、异质性水平、敏感性分析结论、发表偏倚判断；避免只写"差异有统计学意义"却不给效应量。

**可套用的英文叙述骨架**（五步对应五句）：

> *A total of k studies (n = … observations) met the inclusion criteria. The overall effect of X on Y was significantly positive (lnRR = …, 95% CI: …–…). Heterogeneity across studies was substantial (I² = …%), and was partly explained by latitude (meta-regression: β = …, p = …). The pooled estimate remained robust after removing influential cases (standardized residuals > 2; hat values > 2 × mean hat). No significant publication bias was detected (Egger's regression, p = …; Orwin's fail-safe N = …).*

**敏感性与稳健性的判读规则**（审稿人常查的数字）：**标准化残差 > 2** 的效应量为疑似异常值；**hat 值 > 2 倍均值**的研究为强影响点——逐个剔除后重跑模型，看合并效应的方向与显著性是否翻转；翻转了就要在结果里明说"结论由少数研究驱动"，这比被审稿人发现体面得多。**发表偏倚双保险**：Egger 回归显著（p < 0.05）提示偏倚存在，再用 **Orwin 失安全数**回答"还需要多少篇无效结果研究才能推翻当前结论"——失安全数远大于合理遗漏数时结论可信。

**一个叙述上的巧思**：异质性高时，不要把 I² 当"坏消息"一笔带过——地理与生态类 Meta 分析里，**高异质性往往是论文的第二发现**：把 Meta 回归/亚组分析找到的调节变量（纬度、气候带、干扰强度）提升为结果的独立小节来写，从"我们合并不了"翻转成"矛盾背后的空间规律被我们找到了"。

### 1.4.4 Meta 分析写作要点清单

- 明确定义研究问题和效应量；详细说明检索与筛选过程
- **双人独立筛选与数据提取并核对**（降低录入错误的核心方法）；数据提取要看全文而非只看摘要；提前统一结局指标口径（定义、时间节点、效应量类型、比较方向）
- 严格评估纳入研究的质量与偏倚风险（不同研究设计用不同工具：RCT 看随机序列/分配隐藏/盲法/失访；观察性研究看混杂控制与选择偏倚）——**不做质量评估，统计结果只能说明"合并了数据"，不能说明"证据可靠"**
- 选择合适的统计模型（固定/随机效应）并报告模型结构
- 异质性高≠结果不能用：关键是从人群/剂量/时长/结局定义/研究设计等来源**解释异质性**（亚组分析、敏感性分析），而不是回避
- 评估发表偏倚；解释结果的统计学意义与实际意义
- 常见返工点（提前规避）：选题太大无法统一结局、检索式太宽噪音多、筛选标准不一致、数据提取不完整、统计方法与数据类型不匹配、遗漏 PRISMA 关键条目

### 1.4.5 AI 辅助 Meta 分析的边界

可委托 AI：把研究设想拆解为 PICO(T) 框架；为 Web of Science / Scopus 生成含布尔逻辑（AND/OR）与同义词扩展的高级检索式；按纳入/排除标准对摘要做初筛；以 Markdown 表格结构化提取信息（第一作者、年份、研究区域、干预、核心定量结果）。

**但每一环都要加人工保险丝**：

- **检索式**：AI 生成的检索式必须在目标数据库里试跑并记录命中数，人工抽查前 50 条看相关性——同义词扩展过头（噪音爆炸）或不足（漏检）都是常态，以试跑结果为准迭代 2–3 轮再定稿。
- **摘要初筛**：AI 初筛后**人工抽样复核 10%**，统计一致率；对"AI 说不准"的边界文献一律人工裁决。筛选标准中途修改要记录版本（方法部分需报告）。
- **数据提取**：AI 提取的每个数字回原文定位核对；自动抓取的题录可能缺 DOI、把综述/评论误当原始研究——**进入证据表前逐条核验文献类型**。
- **效应量计算与合并**：交给 metafor 等统计软件，不让 AI 直接"算"——AI 可以帮你写 R 代码，但模型结构（随机因子怎么设）必须由你根据数据依赖关系决定。

**AI 不可替代**：纳入研究质量的严格评估；异质性来源（空间尺度、气候带差异）的生态学机制解释；以及最关键的一步——**判断哪些结论是证据支持的、哪些只是统计假象**。科研的核心洞察力始终在于"人"。

## 1.5 文献计量综述与 CiteSpace 实战

### 1.5.1 工具链

- **数据库**：Web of Science 核心合集、CNKI（知网 KVisual）、Scopus
- **软件**：CiteSpace、VOSviewer、Bibliometrix（R 包，`biblioshiny()` 一键可视化）、rabbitresearch

**四大工具怎么选**（综合《图书情报知识》等对比研究与社区经验）：

| 工具 | 强项 | 短板/注意 | 最适合 |
|---|---|---|---|
| **CiteSpace** | 演化呈现独一档（时间线图、关键词突现）；**中文数据免转换兼容好**；图谱视觉易读 | 关键词统计区分单复数，清洗阶段必须合并；Top N 等参数主观性强 | 研究前沿识别、演进路径叙事 |
| **VOSviewer** | 聚类算法更准确；操作简单；网络视图、密度视图丰富 | 无突现检测，时间维度弱 | 合作网络、共现聚类、图谱"颜值" |
| **Bibliometrix / biblioshiny** | 分析维度最全（M/G 指数、三领域图、主题演化、Bradford 定律）；免费开源 | R 门槛；**直接导入 CNKI 中文数据会丢字段** | 全面描述性计量、一图流概览 |
| **Sci2** | 学术计量严谨 | 界面陈旧、上手难 | 方法学取向的计量研究 |

**五条实战提示**（踩坑高发区，社区博客反复验证）：

1. **联用是常态**：完整的知识图谱论文通常 VOSviewer（聚类与合作网络）+ CiteSpace（突现与时间线）联用，部分再加 biblioshiny 的描述性统计——Frontiers 系期刊上的计量综述几乎都是这套组合。
2. **数据源优先级**：尽量用 WoS 核心合集；PubMed 导出缺参考文献字段，Scopus 字段口径与 WoS 不同——**混库合并前必须先对齐字段**，否则引文网络直接断裂。
3. **CNKI → biblioshiny 的回填 workaround**（科学网博客方案）：CNKI 题录先经 CiteSpace 做格式转换 → biblioshiny 导入 → 导出 xls → 把丢失的字段手工/脚本回填——嫌麻烦就中文用 CiteSpace、英文用 biblioshiny 分头做。
4. **先练手再上阵**：biblioshiny 自带样例数据集，先把全流程跑通再换自己的数据；CiteSpace 先用官方 demo 网络熟悉参数含义。
5. **口径一致性**：检索式、下载日期、去重规则写进方法附录——同一检索式隔三个月重跑结果就变了，不写明日期无法复现。

### 1.5.2 Bibliometrix 标准流程（课程实操版）

1. **数据准备**：WoS 导出选 BibTeX 或纯文本格式，记录内容选"全记录与引用的参考文献"，否则无法导入。
2. **导入**：biblioshiny → Data → Load Data → Import Raw File(s) → Database 选 Web of Science → START。
3. **数据筛选**：一般选取**完整年份**的引文数据，按出版年份过滤（如 2017–2022）。
4. **描述性分析**（Overview → Main Information；Annual Scientific Production 看逐年发文量与年际变化率）。
5. **文献来源分析**：最相关来源期刊；**布拉德福定律**识别核心期刊区（与洛特卡定律、齐普夫定律并称文献计量三大定律）；Source Impact 看期刊影响力指数与总被引；来源动态看头部期刊逐年发文变化。
6. **作者影响力分析**：Author Impact 计算 h 指数等。
7. **文献分析**：本地高被引文献（Most Local Cited Documents）、关键词词云、引文关系、主题关系、合作关系。

### 1.5.3 CiteSpace 四要素与"参数陷阱"

任何一篇 CiteSpace 论文都必须交代（审稿人必查）：

1. **数据来源**：检索词、时间跨度、数据库来源（如 WoS 核心合集）；
2. **参数设定**：Time Slicing（时间切片）与 Top N 阈值——**聚类图谱不是绝对真理，而是"每年提取前 N 个高频词"过滤后的主观视觉表征**；
3. **聚类图谱与关键词突现**（Burst Detection）：聚类揭示学术派系的形成，突现词抓取前沿"潜力股"；
4. **人工分析**：优质图谱分析绝不是罗列标签，**人类专家的核心贡献是提供因果解释（The Why）**——例如解释"随机森林"近年突现，是因为高分卫星（Sentinel-2）数据量与异质性激增、传统回归模型无法胜任。

**CiteSpace 综述的常见缺陷（写作时自查）**：只描述图谱不解释机制；不报告 Top N 与切片参数；把参数过滤出的表象当作领域全貌；用"随着时代发展、二者紧密相关"等套话连接突现词——这恰是 AI"蒙眼写作"的典型幻觉（见 sci-paper-writing skill 的 17-ai-collaboration.md）。

**实用经验**（综合高浏览量社区经验）：写之前精读目标层级的高质量论文（推荐关注 Scientometrics 等文献计量专业期刊的行文结构）；关键词合并（同义词、单复数、缩写）要在数据清洗阶段完成；主题可行性用"AI 发散 + 数据库检索"三角验证；图谱截图与数据投喂 AI 辅助解读时，**必须同时提供数据来源与参数设定**，否则生成的结论在科学上无效。

### 1.5.4 文献计量综述的结构模式（课程案例：GEODERMA 数字土壤制图综述，IF 7.4）

一篇规范的文献计量/系统混合型综述的正文骨架：

- **引言**：全球挑战背景（人口、土地退化、气候变化）→ 领域定义（数字土壤制图 DSM 相对传统土壤调查的优势）→ 检索策略（完整列出检索式，如 "digital soil mapping" OR "globalsoilmap" OR "soilgrids"…）
- **现状与趋势**：逐年/逐刊发文频率；研究的空间分布；土壤采样（采样密度、信息缺失比例）；研究对象与深度（如 77.5% 文章涉及 SOC/SOM）；环境协变量与空间分辨率；预测模型谱系（地统计→线性→回归克里金→非线性→模型平均）；验证与不确定性
- **挑战与前景**：当前趋势；遗留数据利用；空间建模与预测瓶颈（输入数据质量、协变量质量、点-像元不匹配、模型预测力）；不确定性量化方法分组（克里金方差、自举、交叉验证、蒙特卡洛、贝叶斯）
- **结论与经验**：编号列出 8–9 条**可操作的建议**（如"应报告采样年份与策略""一半文章只制图表层 <30 cm，深层研究不足""呼吁抢救遗留数据""建议将动态机理模型与静态经验模型结合"）

**启示**：高水平综述的结论不是"研究越来越多"这类废话，而是逐条指出**缺什么、错什么、下一步做什么**。

## 1.6 综述类论文的共同避坑清单

- [ ] 综述有明确的研究问题（PICO），不是泛泛的"研究进展"
- [ ] 检索策略完整可复现（数据库、检索式、时间范围、筛选标准）
- [ ] 有 PRISMA 流程图，排除阶段写明**原因**
- [ ] 图谱/森林图/漏斗图的图例、缩写、单位、坐标标注齐全，读者不必回正文找说明
- [ ] 每个论断有文献支撑，且忠于原文；区分"作者观点"与"文献内容"
- [ ] 讨论部分有作者自己的评价、机制解释与未来方向（综而有述）
- [ ] Meta 分析报告了质量评估、异质性、敏感性分析与发表偏倚
- [ ] CiteSpace 类论文报告了 Time Slicing 与 Top N 等关键参数
